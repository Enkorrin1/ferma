# Запуск USB-фермы

1. Подключите подготовленные телефоны кабелями и подтвердите USB-отладку.
2. Дважды нажмите `Запустить ферму.cmd` в корне проекта.
3. В окне нажмите **Запустить ферму**.
4. Нажмите **Открыть панель** → **Телефоны**.
5. Для уже подготовленных телефонов нажмите **Запустить все** и дождитесь статуса
   **Полностью готов**.
6. Для нового телефона последовательно нажмите **Установить/обновить** и
   **Подключить к Hub**. Одноразовый код передаётся через USB, а токен сохраняется
   приложением в зашифрованном хранилище и не попадает в команды или журнал.
7. При проблеме откройте **Диагностику** или нажмите **Восстановить очередь**.
8. Кладите материалы в платформенные папки через кнопку **Открыть папки**.

Панель автоматически запускает Hub и обработчик очередей, создаёт отдельный `ADB reverse`
для каждого телефона, переключает установленный агент на локальный Hub и восстанавливает
связь после переподключения. Cloudflare Tunnel в USB-режиме не используется.

Вход в соцсети и системное разрешение захвата экрана выполняются человеком один раз.
Установка агента, локальная связь, безопасная выдача токена, восстановление Accessibility,
запуск и перезапуск доступны из центра управления.
